How JalaRaksha Works

1. Observe & Report

Notice a leaking pipe, dripping public valve, or overflowing storage tank? Record it with broad location details. No registration required.

2. Track with Reference Code

Every submission generates a private, unique reference code (e.g., JR-K7B4N9X2QW). Check status updates without compromising your privacy.

3. Verified Resolution

Administrators and student volunteers review reports, coordinate maintenance, and publish verified updates. No false impact metrics.
